# Walkthrough Scope Limitation

Walkthrough files (`walkthrough.md`) generated by the AI coding agent must strictly adhere to the following constraint:

- **Recent Changes Only**: The walkthrough should only list, explain, and document the changes completed in the most recent turn/request.
- **No Cumulative Logging**: Do not append or accumulate changes from previous iterations in the work session. Exclude older accomplishments that are unrelated to the immediate task just completed.
